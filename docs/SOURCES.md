# Sources

- Hersbach, H. et al. (2020). The ERA5 global reanalysis. *Quarterly Journal of the Royal Meteorological Society* 146, 1999-2049.
- Natural Earth 10 m Admin-0 Countries (public domain), Türkiye outline via https://github.com/datasets/geo-countries: https://www.naturalearthdata.com
- Open-Meteo historical weather API (ERA5): https://open-meteo.com/en/docs/historical-weather-api
- ESA WorldCover 10 m (planned for v0.2): https://esa-worldcover.org
- European Forest Fire Information System, country statistics (planned for checking yearly totals): https://effis.jrc.ec.europa.eu
